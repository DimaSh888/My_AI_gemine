# My_AI_gemine

## Отдельные чаты

Теперь переписки хранятся отдельно: модель `Chat` содержит чаты пользователя, а `ChatMessage` связан с конкретным чатом. При обновлении существующей базы миграция `0002_chat_and_message_chat` переносит старые сообщения каждого пользователя в отдельный чат «Старая переписка».

После получения обновлённого проекта:

1. Убедись, что в корне проекта есть `.env` с ключом `GEMINI_API_KEY=твой_ключ`.
2. Активируй виртуальное окружение.
3. Выполни `python manage.py migrate`.
4. Запусти `python manage.py runserver`.

Файл `.env` и локальная база данных не включены в архив. Не загружай ключ API в Git.
